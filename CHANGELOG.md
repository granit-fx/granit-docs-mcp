# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.1.1] - 2026-07-05

### Security

- Override transitive `SQLitePCLRaw.lib.e_sqlite3` 2.1.11 (high-severity
  GHSA-2m69-gcr7-jv3q) pulled by Microsoft.Data.Sqlite with an explicit
  `SQLitePCLRaw.bundle_e_sqlite3` 3.0.3 reference

### Changed

- Dependency updates: ModelContextProtocol 1.4.0, Microsoft.Extensions.\*
  and Microsoft.Data.Sqlite 10.0.9, Markdig 1.3.2, Microsoft.NET.Test.Sdk
  18.7.0

## [1.1.0] - 2026-06-03

### Added

- Multi-repository code search via a `repos.json` file
  (`GRANIT_MCP_REPOS_FILE`, default `~/.granit-mcp/repos.json`): make extra
  repos searchable beyond the built-in `granit-dotnet` / `granit-front`
- Private GitHub repo support — indexes fetched via the authenticated
  Contents API using `GRANIT_MCP_GITHUB_TOKEN`
- Self-hosted GitLab provider support via `GRANIT_MCP_GITLAB_TOKEN` and
  `GRANIT_MCP_GITLAB_HOST` (per-entry `host` override)
- The `repo` parameter of the code tools now accepts any configured repo id

### Changed

- Configured repos augment the built-in defaults; reusing an `id` overrides
  a default. Access is governed by the caller's token — unreachable repos
  are skipped silently
- Dependency updates: ModelContextProtocol 1.3.0, Microsoft.Extensions.\*
  and Microsoft.Data.Sqlite 10.0.8, Markdig 1.2.0, Microsoft.NET.Test.Sdk
  18.6.0, coverlet.collector 10.0.1

## [1.0.0] - 2026-03-26

### Added

- Local .NET 10 dotnet tool replacing the Cloudflare Worker
- SQLite FTS5 full-text search on `llms-full.txt` documentation
- Search/fetch separation: `search_docs` (lightweight) + `get_doc`
  (full content) for ~60-80% token reduction
- Automatic git branch detection from `.git/HEAD` for code index tools
- `BackgroundService` for periodic docs re-indexing (default: 4 hours)
- Graceful degradation during initial indexing
- 9 MCP tools: `docs_search`, `docs_get`, `docs_list_patterns`,
  `code_search`, `code_get_api`, `code_get_graph`,
  `code_list_branches`, `nuget_list`, `nuget_get`
- ADR-003: documents the migration decision

### Changed

- **BREAKING:** Transport changed from HTTP (remote Worker) to stdio
  (local dotnet tool)
- **BREAKING:** Tool `search_granit_docs` renamed to `docs_search`
- **BREAKING:** Tool `get_module_reference` replaced by `docs_get`
- Documentation source changed from `search-index.json` (manual) to
  `llms-full.txt` (auto-generated by Starlight)
- Search engine changed from custom TF-IDF (~120 lines JS) to
  SQLite FTS5 (stemming, phrase matching, prefix search)
- Code index cache changed from Cloudflare KV to in-memory with TTL

### Removed

- Cloudflare Worker deployment (`wrangler.toml`, `deploy.yml`)
- TypeScript codebase (`src/*.ts`, `package.json`, `tsconfig.json`)
- Custom TF-IDF search implementation
- `search-index.json` dependency (replaced by `llms-full.txt`)
- Rate limiting (not needed for local stdio transport)
